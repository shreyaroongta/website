# Portfolio Project Instructions

## Purpose and audience
This is Shreya Roongta's professional Learning Design and Technology portfolio for learning-design hiring managers, instructional-design recruiters, EdTech companies, curriculum-development teams, and faculty or academic reviewers.

## Design principles
Keep it professional, modern, warm, clean, accessible, responsive, content-focused, and consistent. Prefer clear typography, restrained details, and minimal JavaScript.

## Content integrity
Never invent employment, credentials, education, projects, metrics, skills, awards, or outcomes. Use source material Shreya provides and clearly mark missing personal details.

## Project standards
Case studies should generally use: Overview, Challenge, Audience, Design Process, Solution, Tools, Outcome, and Reflection.

## Engineering standards
Before completing substantial changes: run the production build and fix errors; check internal links; inspect responsive layouts; avoid unnecessary dependencies; preserve accessibility and the design system.
